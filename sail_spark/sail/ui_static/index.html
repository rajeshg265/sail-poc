FLIGHTSQL KEEPALIVE
bootstrap.py holds the ADBC connection open — SELECT 1 every 60 s. Prevents Sail evicting the flight-default session and losing all EXTERNAL TABLE registrations.
SPARKCONNECT KEEPALIVE
bootstrap.py fires spark.sql("SELECT 1") every 20 s — pySail evicts idle sessions after ~35 s. On eviction, bootstrap auto-recovers: creates a new session, re-registers all datasets, updates the metadata endpoint so QueryService reconnects transparently on next query.
SC ARROW — ZERO-COPY PATH
At query time, SparkConnectClient.execute() returns raw ArrowBatch.getData() bytes. No JDBC row deserialization — Arrow IPC decoded column-by-column via ArrowStreamReader. Same SparkConnect session as JDBC mode — same keepalive applies.
PGPOOL — ALL SAIL PATHS
bootstrap.py's background refresh thread reads from pgpool, never directly from TimescaleDB. pgpool handles connection pooling per shard and is shared across all Sail engine modes.
